MySimoka SmartGrowth

Kebijakan Privasi

Berlaku sejak 9 Oktober 2026

Kebijakan ini menjelaskan data apa saja yang dikumpulkan dan diproses oleh aplikasi Android MySimoka SmartGrowth beserta dashboard web-nya (admin.mysimoka.id), untuk apa data itu dipakai, bagaimana data disimpan, dan apa hak Anda. Dalam kebijakan ini, "kami" berarti tim pengelola MySimoka.

1. Siapa pengguna aplikasi ini

Aplikasi ini ditujukan untuk guru dan admin sekolah yang mencatat pertumbuhan serta imunisasi siswa. Aplikasi ini tidak ditujukan untuk dipakai oleh anak-anak. Data siswa dimasukkan oleh pihak sekolah.

Untuk data siswa, sekolah adalah pihak yang menentukan tujuan pengumpulan data dan bertanggung jawab memperoleh persetujuan dari orang tua atau wali siswa sesuai ketentuan yang berlaku, termasuk Undang-Undang No. 27 Tahun 2022 tentang Pelindungan Data Pribadi. Kami memproses data tersebut atas nama sekolah untuk menjalankan layanan.

2. Data yang dikumpulkan

a. Data akun pengguna (guru dan admin sekolah)

  • Nama lengkap dan alamat email.
  • Kata sandi. Kata sandi disimpan dalam bentuk hash (bcrypt), tidak dalam bentuk aslinya.
  • Sekolah yang diikuti dan peran di sekolah tersebut (guru atau admin sekolah).

b. Data siswa yang dimasukkan sekolah

  • Identitas: nama lengkap, nomor induk siswa (NIS/NISN), tanggal lahir, jenis kelamin, kelas, alamat, catatan, serta nama dan nomor telepon orang tua atau wali.
  • Hasil pengukuran: tinggi badan, berat badan, tanggal pengukuran, serta nama dan ID alat ukur beserta data mentah dari alat bila alat Bluetooth dipakai. Indeks massa tubuh dan status gizi dihitung dari data ini.
  • Catatan imunisasi: jenis vaksin, dosis, nomor batch, lokasi suntikan, petugas, tanggal, dan catatan kejadian ikutan pasca-imunisasi (KIPI) bila ada.

c. Data wajah siswa

  • Saat mendaftarkan wajah, foto siswa dikirim ke server kami. Foto tersebut diubah menjadi representasi numerik wajah (face embedding), yaitu deretan angka untuk mencocokkan wajah.
  • Yang disimpan hanya representasi numerik tersebut. Foto aslinya tidak disimpan di server.
  • Saat pengukuran, foto dari kamera dipakai untuk mencari siswa yang cocok di sekolah yang sama. Foto ini juga tidak disimpan di server.
  • Fitur pengenalan wajah bersifat opsional. Sekolah tetap bisa mencari siswa secara manual.

d. Data alat ukur

  • Nama dan ID Bluetooth alat ukur yang disambungkan, serta sekolah pemiliknya.
  • Hasil pengecekan akurasi dan kalibrasi alat oleh tim teknis, beserta waktu dan nama akun yang melakukannya.

e. Data yang tidak kami kumpulkan

  • Kami tidak mengumpulkan lokasi Anda.
  • Kami tidak memakai iklan, SDK analitik, atau pelacak di aplikasi. Deteksi wajah di ponsel memakai Google ML Kit, yang berjalan di perangkat; library ini dapat mengirim data diagnostik penggunaan (bukan foto atau data siswa) ke Google sesuai ketentuan ML Kit.
  • Kami tidak membaca kontak, berkas, atau data lain di ponsel Anda.

4. Penggunaan data

Data hanya dipakai untuk menjalankan layanan MySimoka:

  • Masuk ke akun dan membatasi akses sesuai sekolah dan peran.
  • Mencatat dan menampilkan hasil pengukuran serta imunisasi siswa.
  • Mengenali siswa lewat wajah saat pengukuran.
  • Menyusun rekap, grafik, dan status gizi siswa untuk sekolah.
  • Memastikan alat ukur bekerja dengan baik.

Kami tidak menjual data dan tidak membagikannya kepada pihak ketiga untuk iklan atau pemasaran.

5. Siapa yang dapat melihat data

  • Guru dan admin sekolah hanya dapat melihat data sekolahnya sendiri, sesuai perannya.
  • Tim pengelola MySimoka dapat mengakses data untuk keperluan dukungan teknis, pemeliharaan, dan keamanan.
  • Kami akan membuka data kepada pihak berwenang hanya jika diwajibkan oleh hukum.

6. Penyimpanan dan keamanan

  • Data disimpan di server yang dikelola tim MySimoka. Seluruh komunikasi antara aplikasi dan server memakai koneksi terenkripsi (HTTPS).
  • Akses data dibatasi per sekolah dan per peran, baik di server maupun di aplikasi.
  • Di ponsel, aplikasi menyimpan token login dan pengaturan alat agar Anda tidak perlu masuk berulang kali. Data ini terhapus saat Anda keluar dari akun atau menghapus aplikasi.
  • Kata sandi disimpan sebagai hash bcrypt. Token login berlaku 24 jam, dan token pembaruan berlaku 7 hari serta disimpan di server dalam bentuk hash.
  • Kami membuat cadangan basis data setiap hari untuk mencegah kehilangan data. Cadangan disimpan selama 14 hari.

7. Lama penyimpanan

  • Data disimpan selama sekolah masih memakai layanan MySimoka, atau sampai dihapus oleh sekolah.
  • Jika akun atau data dihapus atas permintaan, data tersebut dihapus dari basis data aktif. Salinan di cadangan harian ikut terhapus paling lama 14 hari kemudian.

8. Hak Anda

Anda dapat:

  • Melihat dan memperbarui data akun Anda di menu Profil aplikasi.
  • Meminta penghapusan akun dan data terkait. Caranya dijelaskan di halaman Hapus Akun.
  • Orang tua atau wali siswa yang ingin melihat, memperbaiki, atau menghapus data anaknya dapat menghubungi sekolah. Sekolah dapat mengubah atau menghapus data siswa, atau meneruskan permintaan tersebut kepada kami, termasuk permintaan penghapusan data wajah.

9. Perubahan kebijakan

Kebijakan ini dapat diperbarui jika ada perubahan pada aplikasi atau ketentuan hukum. Tanggal berlaku di bagian atas halaman akan diperbarui, dan perubahan penting akan diberitahukan melalui aplikasi atau kepada sekolah.

10. Kontak

Pertanyaan atau permintaan terkait privasi dapat dikirim ke info@mysimoka.id.
